# Урок 41. Алгоритми — що це таке?

**Тривалість:** 45–60 хв  
**Рівень:** Algorithm Explorer

## 🎯 Місія
Зрозумій алгоритм як точну послідовність дій.

## 🧠 Ключова ідея
```python
numbers = [7, 2, 9, 4, 1]
largest = numbers[0]
for number in numbers:
    if number > largest:
        largest = number
```

## ✏️ Основні завдання
1. Максимум без `max()`.
2. Мінімум без `min()`.
3. Сума без `sum()`.
4. Другий максимум.
