---

## 🧠 1. Що таке змінна

Змінну можна уявити як коробку з підписом.

```python
name = "Marko"
age = 9
coins = 100
```

Тут:
- `name` зберігає `"Marko"`;
- `age` зберігає `9`;
- `coins` зберігає `100`.

Виведемо їх:

```python
print(name)
print(age)
print(coins)
```

---

## 🧪 2. Значення можна змінювати

```python
coins = 100
print(coins)

coins = 150
print(coins)
```

Python виконує код зверху вниз, тому друге значення замінює перше.

---

## ➕ 3. Математика зі змінними

```python
coins = 100
coins = coins + 50
print(coins)
```

Скорочений запис:

```python
coins += 50
coins -= 20
```
