# Урок 46. Stack — Undo

**Тривалість:** 45–60 хв  
**Рівень:** Algorithm Explorer

## 🎯 Місія
Познайомся зі стеком через систему Undo.

## 🧠 Ключова ідея
```python
stack = []
stack.append("draw circle")
stack.append("move player")
last_action = stack.pop()
```

## ✏️ Основні завдання
1. Стек із 5 дій.
2. Undo через `.pop()`.
3. Оброби пустий stack.
4. Покажи верхню дію.

## ⭐ Challenge
Створи просту систему Undo.
