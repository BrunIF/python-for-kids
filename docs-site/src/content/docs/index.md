Цей вебсайт містить навчальний курс «Python для дітей» — практичний курс Python для Марка, учня 4-го класу.

## Як побудований курс

Курс починається з основ — змінних, типів даних і математики — і поступово просувається до функцій, файлів, модулів та графіки з Pygame.

У кожному уроці є:

- **Тривалість і рівень** — орієнтовний час виконання;
- **Місія** — чіткі цілі уроку;
- пояснення простими словами з прикладами;
- **Python-код** для копіювання та запуску;
- **Вправи** для закріплення;
- **Challenge** для додаткового виклику;
- **Debug Challenge** для відпрацювання навичок пошуку помилок;
- **Чек-лист** перевірки;
- **Домашня місія** для самостійної роботи.

## Рівні курсу

1. **Основи Python** — змінні, типи даних, ввід, порівняння, умови.
2. **Цикли та структури** — `for`, `while`, `random`, рядки, списки.
3. **Функції та дані** — функції, словники, вкладені структури.
4. **Файли, помилки, модулі** — збереження даних, `try/except`, власні модулі.
5. **Графіка з Pygame** — вікно, координати, рух, клавіатура, зіткнення.
6. **Фінальний проєкт** — Catch the Coin.

## Фінальна мета

Після курсу Марко має вміти писати Python-програми: від простих обчислень до інтерактивної графічної гри з використанням Pygame.
