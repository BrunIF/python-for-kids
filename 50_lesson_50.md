## Приклад: початок проєкту
```python
class Game:
    def __init__(self):
        self.player = "Marko"
        self.score = 0

    def play(self):
        print(f"{self.player} починає гру!")
        self.score += 10
        print(f"Рахунок: {self.score}")

game = Game()
game.play()
```
