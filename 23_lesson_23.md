## 🎯 Місія
Перенеси поведінку героя всередину його класу.

## 🧠 Ключова ідея
```python
class Player:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

    def take_damage(self, damage):
        self.hp = max(0, self.hp - damage)

    def is_alive(self):
        return self.hp > 0
```

## ✏️ Основні завдання
1. Додай `show_status()`.
2. Додай `attack()`.
3. Не дозволяй HP падати нижче 0.
4. Додай `heal()` та `is_alive()`.
