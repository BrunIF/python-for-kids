# Урок 47. Queue — черга

**Тривалість:** 45–60 хв  
**Рівень:** Algorithm Explorer

## 🎯 Місія
Познайомся з FIFO-чергою через `deque`.

## 🧠 Ключова ідея
```python
from collections import deque

queue = deque(["Slime", "Zombie", "Dragon"])
next_enemy = queue.popleft()
```

## ✏️ Основні завдання
1. Черга ворогів.
2. Додавай у кінець.
3. Бери з початку.
4. Порівняй queue і stack.
