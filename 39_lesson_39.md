# Урок 39. Space Invaders 9 — sprites, звук і polish

**Тривалість:** 45–60 хв  
**Рівень:** Game Developer

## 🎯 Місія
Додай sprites, звуки, стартовий екран і власну механіку.

## 🧠 Ключова ідея
```python
laser_sound = pygame.mixer.Sound("assets/laser.wav")
laser_sound.play()
```

## ✏️ Основні завдання
1. Додай sprites.
2. Додай звуки.
3. Стартовий екран.
4. Власний power-up.

## ⭐ Challenge
